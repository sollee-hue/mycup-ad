# LG myCup 사이니지 광고 제안 페이지

텀블러 세척기(myCup) 화면에 광고를 집행할 브랜드·대행사에게 보내는 제안 페이지입니다.
PC·모바일 하나의 반응형 페이지이며, 빌드 과정 없이 정적 파일만으로 동작합니다.

```
index.html          페이지 전체 (HTML·CSS·JS 한 파일)
img/                소재·설치 사진 16장
apps-script/Code.gs 리드를 구글 스프레드시트에 쌓는 스크립트
```

---

## 1. 배포

### GitHub Pages
1. 이 폴더를 저장소 루트로 올립니다.
2. Settings → Pages → Source를 `Deploy from a branch`, 브랜치는 `main` / `/ (root)`로 지정합니다.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다.

저장소를 Private으로 두면 Pages는 유료 플랜에서만 동작합니다. 무료 플랜이면 저장소를 Public으로 두되, 페이지에 `noindex, nofollow`가 들어 있어 검색에는 잡히지 않습니다.

### Netlify
[app.netlify.com/drop](https://app.netlify.com/drop) 에 **폴더째** 드래그합니다. `index.html` 하나만 올리면 이미지가 전부 깨집니다.
이미 만든 사이트를 갱신할 때는 그 사이트의 **Deploys** 탭에 폴더를 떨어뜨리면 URL이 유지됩니다.

---

## 2. 리드를 구글 스프레드시트로 받기

문의 폼은 두 가지 방식 중 하나로 연결합니다. **A안(스프레드시트 직결)을 권장합니다.**

### A. 스프레드시트로 바로 받기 — 권장

1. 리드를 쌓을 구글 스프레드시트를 새로 만듭니다.
2. **확장 프로그램 → Apps Script**를 열고, 기본 코드를 지운 뒤 `apps-script/Code.gs` 내용을 전부 붙여넣습니다.
3. `Code.gs` 맨 위의 `SECRET` 값을 원하는 문자열로 바꿉니다.
   새 리드가 들어올 때 메일 알림을 받으려면 `NOTIFY_TO` 에 받을 주소를 적습니다.
4. **배포 → 새 배포 → 유형 "웹 앱"**
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** ← 이 설정이 아니면 페이지에서 전송되지 않습니다
5. 배포 후 나오는 `.../exec` 로 끝나는 URL을 복사합니다.
6. `index.html` 에서 `var SHEET = {` 를 찾아 두 값을 채웁니다.

```js
var SHEET = {
  endpoint: "https://script.google.com/macros/s/AKfy.../exec",
  secret:   "3단계에서 정한 SECRET 과 같은 값"
};
```

시트에 아래 열이 자동으로 만들어지고, 문의가 들어올 때마다 한 줄씩 쌓입니다.

| 접수 시각 | 회사/브랜드 | 담당자명 | 휴대폰 | 이메일 | 희망 패키지 | 문의 내용 | 개인정보 동의 | 유입 페이지 |
|---|---|---|---|---|---|---|---|---|

> `Code.gs` 를 고친 뒤에는 **배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다.
> 배포가 살아 있는지 확인하려면 `/exec` URL을 브라우저에서 그냥 열어보세요. `{"ok":true,...}` 가 보이면 정상입니다.

### B. 구글폼으로 받기

`SHEET.endpoint` 를 빈 문자열로 두고 `GFORM` 만 채우면 구글폼으로 전송됩니다.
구글폼 응답도 **응답 → 스프레드시트로 연결**을 누르면 시트로 떨어집니다.

`index.html` 의 `var GFORM = {` 에서:
- `action` — 폼 URL의 끝을 `/viewform` → `/formResponse` 로 바꾼 주소
- `fields` — 폼 미리보기에서 F12를 눌러 각 입력칸의 `name="entry.숫자"` 값을 확인해 넣습니다

## 3. 연결 후 반드시 확인할 것

1. 동의 체크 없이 `광고 문의하기` → 전송되지 않고 붉은 안내가 뜨는지
2. 동의 체크 후 실제 제출 → 시트에 한 줄이 쌓이는지
3. 쌓인 줄의 휴대폰 번호가 `010-1234-5678` 형태로 그대로 들어갔는지

두 방식 모두 브라우저가 응답 본문을 읽지 못하는 경우가 있어, 전송이 끝나면 화면에는 성공으로 표시됩니다. **연결 직후 한 번은 실제로 시트를 열어 확인하세요.**

## 4. 페이지 수정이 잦은 부분

| 내용 | 찾는 방법 |
|---|---|
| 집행 단가·보장 송출 수 | `id="price"` 섹션 |
| 설치 거점 목록 | `id="where"` 섹션 |
| 개인정보 보유 기간 | `class="consent-detail"` |
| 하단 연락처 | 파일 맨 아래 `<footer>` |

## 5. 페이지에 남겨둔 고지

소개서 수치를 인용하면서 함께 밝혀야 하는 내용을 하단 "고지사항"에 넣어두었습니다. 수치만 따로 떼어 쓸 때도 아래는 같이 가야 합니다.

- 사이니지 화면 이미지는 매체 이해용 예시이며 생성형 AI로 제작, 실존 브랜드와 무관
- 패키지·단가는 PoC 단계 기간 한정 특가, VAT 별도
- 보장 송출 수는 세로+가로 세트 1구좌(각 15초) / 4주 집행 기준
- 설치 기기는 지속 확대 중
